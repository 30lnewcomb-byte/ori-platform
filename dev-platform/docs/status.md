## Deliberately not exposed as primary UI

Search, Projects, Tasks, Activity, and broad Settings controls are not presented as finished everyday product features until their underlying behavior exists.

## Completion rule

A route is not a feature merely because it can render.

The product, backend behavior, persistence, security boundary, and displayed state must agree before a capability is treated as complete.
