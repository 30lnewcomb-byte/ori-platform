# Ori Developer Docs

This is the canonical source for the Ori Developer Platform documentation.

The web docs experience is served at `/developer/docs`, but its documentation belongs to the Developer Platform and is maintained from this directory.

## Sections

- Getting started
- Platform overview
- API reference
- Authentication
- Projects
- Tools
- SDKs
- Guides

## Documentation rule

Only implemented capabilities are documented as available. Planned capabilities must be clearly labeled as planned or in development.
