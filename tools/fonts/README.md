# Ori font system

Ori treats typography as three separate font families.

- Ori Text — UI, chat, and documentation.
- Ori Display — branding and major headings.
- Ori Mono — code, logs, and technical data.

The first starter cut derives from the open-source Inter 4.0 family. Ori Text uses Inter Regular, Ori Display uses Inter Display Regular, and Ori Mono uses Inter Regular with fixed-width metrics.

This is a starter cut, not the final Ori typeface. The build is reproducible so dedicated Ori glyph refinements can replace the starter outlines later without changing application roles.

The first web cut ships ASCII U+0020–U+007E. Expand the range when more languages or symbols are needed.

See OFL-1.1.txt for the source font license.
